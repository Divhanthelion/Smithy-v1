# Analysis of competing hypotheses

Read this when hypotheses are frozen and you are scoring evidence. Do not use it to generate a favorite story.

## Rules

- Hypotheses are mutually exclusive and frozen. New favorites after evidence arrives are confirmation bias with extra steps. The only unfreeze is a re-open of the pin in `SKILL.md` — not a quiet extra row here.
- Subtopics are not hypotheses. If the set is a table of contents, stop scoring and send it back to the pin.
- Score **against** every hypothesis, not for the one you like.
- **Diagnosticity** is the point. Evidence consistent with every hypothesis has weight zero. One verified inconsistency can kill a hypothesis.
- Do not sum pluses and minuses. A numeric total is fake precision on subjective cells.
- Absent evidence is evidence when the hypothesis required it to be present. Write that down.

## Procedure

1. List the frozen hypotheses. If two are the same claim in different clothes, merge them before scoring.
2. List evidence items (including absences). Each item is a Findings bullet you already fetched.
3. For each item × hypothesis: consistent / inconsistent / irrelevant. Irrelevant drops out of the matrix.
4. Drop non-diagnostic rows (consistent or irrelevant for everyone).
5. Rank hypotheses by the **inconsistent** diagnostic evidence against them. Least disproved first. Not most confirmed.
6. Sensitivity: name the one or two items which, if wrong or deceptive, would flip the ranking. If you cannot name them, you don't have a ranking — you have a vibe.
7. Report all hypotheses in Disconfirmation. Rejected ones need the killing evidence. Survivors need what would kill them next.
8. Watch: name observations *not already in hand* that would move the ranking. Sensitivity is "if this evidence is wrong." Watch is "if the world does X." Put them in Watch.
9. If the ranking depends on a source you failed to laterally verify, go back to `sift.md` before writing Implication.

## Output

The note's **Disconfirmation** section is the product. A working matrix may exist in the chat; don't dump an unscored grid into the file.

If every hypothesis is still standing, say so. That is a finding. Inventing a winner is a defect.
